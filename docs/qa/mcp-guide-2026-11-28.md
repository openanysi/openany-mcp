## Changes

- Remove fixed catalog totals from the guide; direct agents to `openany_overview` and distinguish MCP scope from whole-market counts.
- Describe execution as supported model/API calls. Keep Chat Completions, non-streaming and response-format boundaries explicit.
- Replace flat per-call claims with the resource's published billing unit and charge conditions.
- Describe compatible Streamable HTTP clients and secure Authorization configuration; do not promise OAuth or universal client support.
- Add clickable key/configuration links and links to existing facts, agent and authentication documents. Reuse the website's client examples rather than adding unverified configuration recipes.
- Add a clean endpoint copy control, keyboard focus and live success/failure feedback. Clipboard writes contain only `https://mcp.openany.si`; there is no network request or secret input.
- Mirror public UI foundation sizing/colors: white canvas, neutral text, blue links, 14px body, 16px/24px section titles, shallow corners and light separators. Use system font fallbacks without remote font dependencies.
- Keep basic developer reference expanded; keep deployment reference separately collapsed. Preserve all deployment reference in the plaintext response.
- Wrap tables in keyboard-focusable local scroll regions rather than widening the mobile document.
- Add a guide-only local preview command that never loads `.env`, a catalog, database credentials or an execution gateway.

## Preview and reproduction

Run `go run ./scripts/preview-guide -listen 127.0.0.1:5290` without service configuration.

- English: `http://127.0.0.1:5290/`
- Chinese: `http://127.0.0.1:5290/?lang=zh`
- This server is a document preview, not a live MCP endpoint. It rejects POST and adds a noindex response header.

Run `node scripts/test-guide-browser.mjs` with Playwright and Chrome available. If Playwright is not locally installed, set `PLAYWRIGHT_MODULE` to an existing installation. Optional overrides: `GUIDE_PREVIEW_URL`, `GUIDE_QA_DIR`. No dependency was added to the production package.
